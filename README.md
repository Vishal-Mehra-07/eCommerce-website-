  <h1>🛍️ eCommerce Website</h1>
  <p>
    An interactive <strong>front-end eCommerce web application</strong> built using 
    <strong>HTML, CSS, and JavaScript</strong>.<br>
    This project simulates an online shopping platform where users can browse products, 
    view details, and add them to their cart.
  </p>

  <h2>📁 Project Structure</h2>
  <div class="highlight">
    <pre>
eCommerce-website/
│
├── index.html          # Main homepage of the store
├── style.css           # Main stylesheet
└──  new.js              # JavaScript for interactivity

  </pre>
  </div>

  <h2>⚙️ Features</h2>
  <ul>
    <li>✅ <strong>Modern UI</strong> — Clean and responsive design</li>
    <li>✅ <strong>Product Showcase</strong> — Display items dynamically</li>
    <li>✅ <strong>Add to Cart</strong> — Simple cart functionality</li>
    <li>✅ <strong>Interactive Buttons</strong> — JS-powered interactions</li>
    <li>✅ <strong>Reusable Layout</strong> — Header, footer, and product card components</li>
  </ul>

  <h2>🚀 Getting Started</h2>
  <ol>
    <li><strong>Clone the repository:</strong>
      <pre><code>git clone https://github.com/Vishal-Mehra-07/eCommerce-website-.git</code></pre>
    </li>
    <li><strong>Open the project:</strong>  
      Open <code>index.html</code> in your browser.
    </li>
    <li><strong>Customize:</strong>  
      Edit <code>style.css</code> for design,  
      <code>new.js</code> for interactivity,  
      and <code>index.html</code> for content.
    </li>
  </ol>
